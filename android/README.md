# Mijote Android app

Native Android client (Kotlin / Jetpack Compose). Package: `app.mijote`.

- Build the debug APK: `./gradlew :app:assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
- Render screenshots on the JVM (Paparazzi): `./gradlew :app:recordPaparazziDebug`

Current state: project skeleton with the theme and the home screen (sample data) from `prototypes/theme-playground/`.
